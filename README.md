# Makerere University Christian Union (MUCU) Website

A fully working, responsive static website for **Makerere University Christian Union (MUCU / MukCU)** — a student-led Christian fellowship at Makerere University, Kampala, Uganda.

## What's included
- `index.html` — Home (hero, what we do, call to action)
- `about.html` — Our story, vision, mission, values, where we meet
- `events.html` — Weekly rhythm + featured events
- `gallery.html` — Photo gallery with lightbox
- `contact.html` — Contact details + working contact form
- `css/style.css` — Responsive, MUCU-branded styling (royal blue & gold)
- `js/main.js` — Mobile nav, active-link highlighting, lightbox, form handling
- `assets/images/` — Research photos (Makerere Main Building, MUCU fellowship & jubilee)

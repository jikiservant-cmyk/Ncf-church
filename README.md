# Makerere University Christian Union (MUCU) Website

A fully working, responsive static website for **Makerere University Christian Union (MUCU / MukCU)** — a student-led Christian fellowship at Makerere University, Kampala, Uganda.

## Design
Built as a faithful clone of **St Francis Chapel Makerere** (stfrancischapelmakerere.org) — the clean WordPress/Elementor-style church website:
- Dark header (`#1a1a1a`), clean white background, generous spacing
- Hero section with large "Welcome to Makerere Christian Union" typography
- Feature boxes: "Make Disciples For Jesus Christ" + "The Path of Discipleship"
- Ministries grid, Sermons with audio players, Events, Announcements, Banns of Marriage
- Give section with 2 Corinthians 9:7 verse
- Dark footer with contact info, worship times, and social links
- Sticky navbar with the official Makerere University logo as brand mark
- Responsive mobile menu, contact form, scroll animations

## What's included
- `index.html` — Home (hero, feature boxes, ministries, sermons, events, announcements, banns, give)
- `about.html` — Our story, vision, mission, values
- `events.html` — Weekly fellowship rhythm + featured events
- `sermons.html` — Sermons listing with audio players
- `donate.html` — Online giving + bank details
- `contact.html` — Contact details + working contact form
- `css/style.css` — Custom styles matching St Francis Chapel Makerere design
- `js/main.js` — Mobile nav, contact form, active nav highlighting
- `assets/images/` — Makerere logo + hero/ministry/sermon photos
